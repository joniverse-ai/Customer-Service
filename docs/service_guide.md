# 디자인코(DesignCo) 서비스 가이드

## 1. 회사 소개

디자인코는 온라인 기반 로고·브랜딩 디자인 전문 에이전시입니다. 모든 작업은 온라인으로 접수·진행·납품되며, 전담 디자이너가 1:1로 배정되어 프로젝트를 수행합니다.

---

## 2. 서비스 종류 및 가격

### 2.1 로고 디자인

| 패키지 | 시안 수 | 수정 횟수 | 납품 파일 | 작업일 | 가격(VAT 별도) |
|--------|---------|----------|----------|--------|---------------|
| 베이직 | 2개 | 3회 | AI, PNG, JPG | 5영업일 | 330,000원 |
| 스탠다드 | 3개 | 5회 | AI, PNG, JPG, PDF, SVG | 7영업일 | 550,000원 |
| 프리미엄 | 5개 | 무제한 | AI, PNG, JPG, PDF, SVG + 원본 소스 | 10영업일 | 880,000원 |

- 시안 수: 초안 시안 개수를 의미하며, 확정 후 선택한 1개 시안을 기준으로 수정 작업이 진행됩니다.
- 작업일: 영업일 기준이며, 주말·공휴일은 제외됩니다.
- 긴급 작업: 작업일 50% 단축 시 추가 요금 30%가 부과됩니다.

## 3. 작업 프로세스

### 3.1 전체 흐름

1. **상담 및 견적** → 2. **계약 및 결제** → 3. **브리핑** → 4. **초안 시안 제작** → 5. **시안 선택 및 수정** → 6. **최종 확인** → 7. **납품**

### 3.2 단계별 상세

| 단계 | 설명 | 소요 시간 |
|------|------|----------|
| 상담 및 견적 | 고객 요구사항 파악, 견적서 발송 | 1영업일 이내 |
| 계약 및 결제 | 전자계약서 서명, 착수금 결제 | 결제 확인 후 착수 |
| 브리핑 | 브리핑 폼 작성 (브랜드 방향, 선호 스타일, 참고 이미지) | 고객 제출 후 1영업일 내 확인 |
| 초안 시안 제작 | 패키지별 시안 수에 따라 초안 제작 | 패키지별 작업일 참조 |
| 시안 선택 및 수정 | 1개 시안 선택 후 수정 진행 | 수정 1회당 2영업일 |
| 최종 확인 | 최종 시안 승인 요청 | 승인 후 1영업일 내 납품 |
| 납품 | 파일 전달 및 저작권 이전 완료 | 결제 완료 확인 후 |

### 3.3 프로젝트 상태 코드

| 상태 | 설명 |
|------|------|
| PENDING | 결제 대기 중 |
| BRIEFING | 브리핑 폼 대기 또는 확인 중 |
| IN_PROGRESS | 시안 제작 중 |
| REVIEW | 시안 검토 대기 (고객 피드백 대기) |
| REVISION | 수정 작업 중 |
| FINAL_CHECK | 최종 확인 대기 |
| COMPLETED | 납품 완료 |
| CANCELLED | 취소됨 |

## 4. 수정 정책

### 4.1 기본 수정 횟수

- 패키지에 포함된 수정 횟수 내에서는 추가 비용 없이 수정이 가능합니다.
- 수정 횟수는 **고객이 피드백을 제출한 횟수** 기준으로 카운트됩니다.
- 한 번의 피드백에 여러 수정사항을 포함해도 1회로 카운트합니다.

### 4.2 추가 수정 비용

| 서비스 유형 | 추가 수정 1회 비용 |
|------------|------------------|
| 로고 디자인 | 55,000원 |
| BI 패키지 | 88,000원 |
| 단품 서비스 | 33,000원 |

### 4.3 수정 범위

**수정에 포함되는 것:**
- 색상 변경
- 서체 변경
- 레이아웃 미세 조정
- 크기/비율 조정
- 텍스트 내용 변경

**수정에 포함되지 않는 것 (추가 시안 비용 발생):**
- 컨셉 자체의 변경 (완전히 새로운 방향)
- 초안 시안에 없는 새로운 디자인 요청
- 확정 후 다른 시안으로 변경

컨셉 변경 시 추가 시안 비용: 로고 165,000원, BI 패키지 275,000원

### 4.4 수정 요청 기한

- 시안 전달일로부터 **7영업일 이내**에 피드백을 제출해야 합니다.
- 7영업일 경과 시 해당 시안이 확정된 것으로 간주합니다.
- 최종 납품 후 수정 요청은 납품일로부터 **14일 이내**에만 가능하며, 추가 수정 비용이 적용됩니다.

## 5. 작업 기간 안내

### 5.1 기준 작업일

- 모든 작업일은 **영업일(월~금)** 기준입니다.
- 작업일 기산점: **착수금 결제 확인 + 브리핑 폼 제출 완료** 시점
- 고객 피드백 대기 기간은 작업일에서 제외됩니다.

### 5.2 긴급 작업

- 긴급 작업은 작업일을 50% 단축합니다.
- 긴급 작업 추가 요금: 해당 서비스 가격의 **30%**
- 긴급 작업 가능 여부는 디자이너 일정에 따라 다르며, 상담 시 확인됩니다.
- 긴급 작업은 접수 후 취소가 불가합니다.

### 5.3 작업 지연

- 디자인코 귀책 사유로 작업일이 초과된 경우, 초과일 1영업일당 총 작업 비용의 **2%**를 할인합니다.
- 최대 할인율은 총 작업 비용의 **20%**입니다.
- 고객 귀책 사유(피드백 지연, 브리핑 미제출 등)로 인한 지연은 해당되지 않습니다.

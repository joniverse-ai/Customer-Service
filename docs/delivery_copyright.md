# 디자인코(DesignCo) 납품 및 저작권 가이드

## 1. 납품 파일 형식

### 1.1 패키지별 기본 납품 파일

| 패키지 | 납품 파일 형식 |
|--------|-------------|
| 로고 베이직 | AI, PNG(배경 투명), JPG |
| 로고 스탠다드 | AI, PNG(배경 투명), JPG, PDF, SVG |
| 로고 프리미엄 | AI, PNG(배경 투명), JPG, PDF, SVG + 원본 소스 파일 |
| BI 베이직 | AI, PNG, JPG, PDF (로고 + 컬러/서체 가이드) |
| BI 스탠다드 | AI, PNG, JPG, PDF (로고 + 스테이셔너리 + 가이드) |
| BI 프리미엄 | AI, PNG, JPG, PDF, INDD (전체 + 브랜드 가이드북 + 패키지) |

### 1.2 파일 규격

- PNG: 최소 3000x3000px, 300dpi, 배경 투명 포함
- JPG: 최소 3000x3000px, 300dpi
- AI: Adobe Illustrator CC 호환 (텍스트 아웃라인 처리)
- SVG: 웹 최적화 버전
- PDF: 인쇄용 CMYK + 웹용 RGB 각 1부

### 1.3 추가 파일 요청

- 기본 납품 외 추가 파일 형식 요청 시: **건당 22,000원**
- 요청 가능 형식: EPS, PSD, TIFF, WebP, ICO(파비콘) 등
- 크기/해상도 변환: **건당 11,000원**

## 2. 납품 방식

### 2.1 기본 납품

- 클라우드 링크(Google Drive)를 통해 전달
- 링크 유효 기간: 납품일로부터 **90일**
- 90일 경과 후 재전송 요청 시: **건당 11,000원**

### 2.2 납품 조건

- 잔금 결제 완료 확인 후 납품
- 최종 확인(승인) 완료 후 영업일 기준 **1일 이내** 납품
- 납품 파일 확인 요청: 수령 후 **3영업일 이내** 파일 이상 여부 확인 및 연락

## 3. 저작권 규정

### 3.1 저작권 이전

- 잔금 결제 완료 시 해당 디자인의 **저작재산권**이 고객에게 이전됩니다.
- 저작인격권(성명표시권, 동일성유지권)은 디자인코에 귀속됩니다.
- 저작권 이전 범위: 해당 프로젝트에서 최종 확정된 디자인에 한함

### 3.2 저작권 이전에 포함되는 것

- 확정된 최종 디자인의 상업적 사용
- 상표 등록 출원 (단, 등록 절차 및 비용은 고객 부담)
- 인쇄물, 웹, 간판, 패키지 등 모든 매체에 적용
- 디자인 변형 및 2차 저작물 작성 (원본 소스 제공 패키지에 한함)

### 3.3 저작권 이전에 포함되지 않는 것

- 미선택 시안(탈락 시안)에 대한 권리 → 디자인코 귀속
- 프로젝트 취소 시 중간 산출물에 대한 권리 → 디자인코 귀속
- 원본 소스 파일이 포함되지 않은 패키지에서의 소스 파일 → 별도 구매 필요

### 3.4 원본 소스 파일

- **프리미엄 패키지**: 기본 포함
- **스탠다드/베이직 패키지**: 별도 구매 가능
  - 로고 원본 소스: **110,000원**
  - BI 원본 소스: **220,000원**
- 원본 소스에는 레이어가 분리된 AI/PSD 파일, 사용 폰트 파일(라이선스 범위 내), 컬러 코드표가 포함됩니다.

### 3.5 포트폴리오 사용

- 디자인코는 납품된 디자인을 포트폴리오 목적으로 사용할 수 있습니다.
- 포트폴리오 비공개를 원하실 경우 계약 시 별도 요청해 주세요.
- 비공개 요청 시 추가 비용은 없습니다.

## 4. 상표 등록 관련 안내

- 디자인코는 디자인 제작만 담당하며, 상표 등록 대행은 하지 않습니다.
- 상표 등록 전 유사 상표 검색은 고객이 직접 수행해야 합니다.
- 상표 등록 거절로 인한 디자인 수정은 추가 수정 비용이 적용됩니다.
- 상표 등록용 파일 규격 변환은 기본 납품에 포함되어 있습니다.

# 디자인코(DesignCo) 환불 및 취소 정책

## 1. 취소 및 환불 기본 원칙

- 환불은 프로젝트 진행 단계에 따라 차등 적용됩니다.
- 환불 요청은 고객센터 또는 마이페이지에서 접수할 수 있습니다.
- 환불 처리 기간: 환불 승인일로부터 **영업일 기준 5~7일** (결제 수단에 따라 상이)

---

## 2. 단계별 환불 규정

### 2.1 착수 전 취소

| 시점 | 환불율 | 비고 |
|------|--------|------|
| 결제 후 24시간 이내 (브리핑 미제출) | 100% | 전액 환불 |
| 결제 후 24시간 경과 ~ 브리핑 제출 전 | 100% | 전액 환불 |
| 브리핑 제출 후 ~ 작업 시작 전 | 90% | 기획 착수 비용 10% 공제 |

### 2.2 작업 중 취소

| 시점 | 환불율 | 비고 |
|------|--------|------|
| 초안 시안 전달 전 | 70% | 작업 진행분 30% 공제 |
| 초안 시안 전달 후 ~ 시안 선택 전 | 50% | |
| 시안 선택 후 (수정 단계 진입) | 30% | |
| 최종 확인 요청 후 | 환불 불가 | 작업 완료 단계 |

### 2.3 납품 후

- 납품 완료 후에는 환불이 불가합니다.
- 단, 디자인코 귀책 사유(계약 내용과 현저히 다른 결과물)에 한해 협의 후 부분 환불 가능합니다.

---

## 3. 환불 불가 항목

다음의 경우 환불이 불가합니다:

1. **긴급 작업** 접수 후 취소
2. **추가 수정 비용**: 이미 수행된 수정 작업에 대한 비용
3. **추가 시안 비용**: 컨셉 변경으로 인한 추가 시안 제작 비용
4. 고객의 단순 변심으로 인한 납품 완료 후 환불
5. 제3자에 의한 무단 사용, 변형으로 인한 문제

---

## 4. 환불 절차

1. 고객센터에 환불 사유와 함께 요청 접수
2. 담당자 검토 (영업일 기준 1~2일)
3. 환불 승인 또는 협의 안내
4. 승인 시 환불 처리 (영업일 기준 5~7일)

---

## 5. 결제 방법별 환불 안내

| 결제 수단 | 환불 방식 | 소요 기간 |
|----------|----------|----------|
| 신용카드 | 카드사 취소 | 3~5영업일 |
| 계좌이체 | 원래 계좌로 환불 | 5~7영업일 |
| 가상계좌 | 환불 계좌 별도 등록 필요 | 5~7영업일 |

---

## 6. 프로젝트 일시 중단

- 고객 사정으로 프로젝트를 일시 중단할 수 있습니다.
- 중단 가능 기간: 최대 **30일**
- 30일 초과 시 프로젝트는 자동 취소되며, 해당 시점의 환불 규정이 적용됩니다.
- 중단 중에도 이미 진행된 작업분에 대한 비용은 공제됩니다.
- 중단 후 재개 시, 디자이너 재배정이 필요할 수 있으며 이 경우 추가 작업일이 소요될 수 있습니다.

---

## 7. 디자인코 귀책 사유 환불

다음의 경우 디자인코 귀책으로 인정됩니다:

- 약속된 작업 기한을 영업일 기준 5일 이상 초과한 경우 (고객 피드백 지연 제외)
- 계약서에 명시된 서비스 항목이 누락된 경우
- 동일한 디자인을 다른 고객에게 중복 제공한 경우

디자인코 귀책 시 환불율은 미완료 작업 비율에 따라 **50~100%** 범위에서 협의합니다.
